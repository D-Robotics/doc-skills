# format-check — 格式自检

检查文档的排版格式，确保符合写作规范。

## 检查规则

### 中英文间距

- 中文与英文之间必须有空格：`使用 XBurn 烧录` ✅，`使用XBurn烧录` ❌
- 中文与数字之间必须有空格：`需要 2 根线` ✅，`需要2根线` ❌
- 中文与行内代码之间必须有空格：`选择 `secure` ` ✅，`选择`secure`` ❌
- 中文与 Markdown 链接之间必须有空格：`本文档 [镜像下载](#镜像下载) 中` ✅，`本文档[镜像下载](#镜像下载)中` ❌

### 日期格式

- 中文文档日期用 `YYYY-MM-DD`：`2026-08-04` ✅
- 不要用中文数字日期：`2026年8月4日` ❌

### 代码块

- 代码块必须标注语言：```` ```bash ```` / ```` ```text ```` / ```` ```python ````
- 不要用裸代码块：```` ``` ```` ❌

### 表格

- 表格占满宽度（Docusaurus 渲染需要）
- 表格单元格内换行用 `<br />`（带斜杠+空格），不用 `<br>`（无斜杠会触发 MDX 报错）

### 链接

- 相对链接用 `./` 前缀 + `.md` 后缀：`[page](./other.md)` ✅
- 不要用不带后缀的链接：`[page](./other)` ❌ 或绝对路径

### 图片

- 图片 URL 必须用 `https://`：`https://rdk-doc.oss-cn-beijing.aliyuncs.com/...` ✅
- 不要用 `http://`：`http://rdk-doc.oss-cn-beijing.aliyuncs.com/...` ❌

## 忽略

- 代码块内的内容
- 行内代码内的内容
- URL

## 输出示例

```text
✅ format-check 通过，未发现格式问题。
```

```text
❌ format-check 发现 5 处格式问题：

  8: 中英文之间缺空格 "使用XBurn烧录" → "使用 XBurn 烧录"
  15: 代码块未标注语言，第 15 行
  23: 日期格式错误 "2026年8月4日" → "2026-08-04"
  31: 相对链接缺少后缀 "./quick-start" → "./quick-start.md"
  42: 中文与链接之间缺空格 "本文档[镜像下载](#镜像下载)中" → "本文档 [镜像下载](#镜像下载) 中"
```
