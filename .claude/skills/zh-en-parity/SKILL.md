# zh-en-parity — 中英文对照检查

翻译完成后，逐文件比对中英文文档的结构一致性。不检查翻译质量（那是 en-check 的活），只检查**结构对等**——中文有的，英文也得有。

## 检查规则

### 1. 图片数量与路径

- 中文文件的 `<img` 数量 = 英文文件的 `<img` 数量
- 每张中文图在英文版有对应位置，次序一致
- 英文版图片 OSS 路径中的语言目录应为 `en/`（非 `zh/`）
- 英文版图片文件名应是英文版实际存在的（不是中文版文件名硬猜）

### 2. 图片格式

- 英文版 `<img>` 标签属性与中文版对齐：`alt` 非空、`src` 用 `https://`（非 `http://`）、缩进与中文源文件一致
- `style` 属性值一致（`width`、`height`、`align`）

### 3. 链接数量与路径

- 中文文件的 `[` 链接数 = 英文文件的 `[` 链接数（不含自动生成的锚点目录）
- 跨仓库链接（`developer.d-robotics.cc`）英文版路径加 `/en/`
- 站内相对链接（`../../xxx/yyy.md`）中英文路径一致

### 4. DocScope 数量与参数

- 中文文件的 `<DocScope` 数量 = 英文文件的 `<DocScope` 数量
- 每个 `<DocScope>` 的 `versions` 和 `products` 参数值一致

### 5. 步骤编号数量

- 有序列表（`1.` `2.` `3.`）的步骤数一致
- 无序列表（`-` `*`）的条目数一致（排除内容差异，只看结构）

### 6. 行内代码值

- 反引号包裹的 UI 值（产品类型、存储介质、连接类型、下载模式等）中英文一致
- 注意区分：中文文件里 `RDK X5` 英文也应该是 `RDK X5`（不是 `X5`），反之亦然

### 7. 警告块/提示块

- `:::` 块数量一致（`:::warning`、`:::tip`、`:::note` 等）
- 块类型一致

### 8. 表格行列

- 表格数量一致
- 每个表格的列数、行数一致（表头行算入）

## 忽略

- 翻译措辞差异（这不是翻译质量检查）
- 中英文自然段落长度差异
- 标点符号差异（中文 `。` vs 英文 `.`）
- 代码块内容
- 手动编号的 H1（中文可能 `# 1.2` 英文 `# 1.2` 一致即可）

## 输出示例

```text
✅ zh-en-parity 通过，中英文结构一致。
```

```text

  upgrade-miniboot.md:
    - 图片数量不一致：中文 2 张，英文 1 张（缺 X5 Module 硬件连接图）
    - 英文图片路径含 zh/ 应为 en/：zh/x5_module/nand_insatll_hardware_connection.png
    - 英文版 <img> 缺 alt 属性（第 66 行）

  burn-sd-card.md:
    - 链接数量不一致：中文 3 个，英文 2 个
    - 英文版 RDK Studio 链接缺 /en/：rdk_studio_doc/category/2-quick-start → rdk_studio_doc/en/category/2-quick-start
```
